# MoniWiki 패치 (HyacinthWiki)

[HyacinthWiki](https://hyacinth.kr)에서 사용 중인 [MoniWiki](https://github.com/wkpark/moniwiki) 패치 공개용 저장소입니다.
커스터마이즈하거나 버그를 수정한 파일만 원본과 같은 경로에 담고 있으며, 위키 전체 소스가 아니므로 단독으로는 동작하지 않습니다.

기준 원본: MoniWiki 1.2.4-RC2

## 적용 방법

MoniWiki 설치 디렉터리에 같은 경로로 덮어씁니다.

```sh
cp plugin/sitemap.php /path/to/moniwiki/plugin/
```

## 라이선스

원본과 동일하게 GPL v2를 따르며, 개별 파일의 저작권 표시는 원본 그대로 유지합니다.
